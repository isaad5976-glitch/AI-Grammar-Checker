# AI Grammar Checker

An AI-powered grammar correction web application built using HTML, CSS, JavaScript, and the Hugging Face Inference API.

## Features

- Corrects grammar and spelling using AI
- Clean and responsive user interface
- Real-time grammar correction
- Built with modern JavaScript

## Technologies Used

- HTML5
- CSS3
- JavaScript
- Git & GitHub

## How to Run

1. Clone this repository.
2. Open `script.js`.
3. Replace the token placeholder with your own Hugging Face API token.
4. Open `index.html` in your browser or run it using a local server.
